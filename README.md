# AuSecours - النجدة 🚨

Tunisia's premier AI-powered emergency first-aid platform.

## Features
- 🤖 AI Emergency Assistant (Gemini 1.5 Flash)
- 🏥 Real-time Hospital Radar Map
- 📞 Emergency Numbers Directory
- 🎓 First Aid Training Registration
- 🌍 Multi-language: AR / FR / EN / Tunisian Derja
- 💚 CPR Metronome & Voice Guidance

## Tech Stack
- React 19 + TypeScript + Vite
- TailwindCSS v4
- Supabase (registrations & reviews)
- Leaflet (hospital map)
- Framer Motion (animations)

## Environment Variables
Copy `.env.example` to `.env.local` and fill in your keys:

```
VITE_GEMINI_API_KEY=your_gemini_key
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Deploy
The project is configured for one-click Vercel deployment via `vercel.json`.
